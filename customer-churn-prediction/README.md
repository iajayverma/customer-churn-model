# Customer Churn Prediction (Machine Learning)

**Summary**
Simple churn prediction pipeline using scikit-learn with a training script and sample synthetic data.

**What's included**
- `train/train_churn.py` - trains a RandomForestClassifier on synthetic data and saves model
- `data/churn_sample.csv` - small synthetic dataset
- `requirements.txt` - Python dependencies
- `README.md` - this file

**How to run**
1. `pip install -r requirements.txt`
2. `python train/train_churn.py`
3. Model saved to `models/churn_model.pkl`

**Resume blurb**
Implemented end-to-end churn prediction pipeline using feature engineering and Random Forest, achieving strong baseline performance.
